# 🏫 스마트 칠판 단일 학급 전용 도구 (Classboard SPA)

스마트 칠판 및 대형 전자칠판 환경에 최적화된 **단일 학급 전용 원터치 대시보드**입니다.  
복잡한 학년/반 선택 단계를 완전히 제거하여 칠판 브라우저를 켜자마자 바로 우리 반 화면으로 열리며, 학생 이름 등 개인정보 노출 없이 **출석 번호(1번~N번)**만으로 안전하고 간편하게 수업 및 학급을 운영할 수 있습니다.

---

## 🌟 주요 핵심 기능

### 1. 상시 출결 & 번호 필터 바 (Sticky Header)
- **52px+ 대형 원터치 칩**: 스마트 칠판에서 장갑을 끼거나 손가락 터치 시 오작동이 없도록 넉넉한 터치 영역 확보.
- **원터치 출석/결석 토글**: 터치 시 출석(초록/파랑) ↔ 결석(회색/취소선) 즉시 전환.
- **실시간 출결 카운터**: `출석 학생수 / 전체 인원 (출석률 %)` 상시 표시.
- **자동 연동 제외 풀**: 결석 처리된 번호는 발표 번호 추첨 및 모둠 자동 편성 대상에서 즉시 자동 제외됩니다.

### 2. [Tab 1] 발표 번호 추첨 & 자동 모둠 편성
- **발표 번호 추첨기**:
  - **비복원 추첨(기본)**: 이미 당첨된 번호는 중복 추첨되지 않으며, 당첨 이력 뱃지로 누적 기록.
  - **복원/비복원 토글**: 언제든 중복 허용 방식으로 전환 가능.
  - **시각/청각 연출**: 디지털 롤링 애니메이션, Web Audio API를 활용한 긴장감 넘치는 비프음, 당첨 시 팡파르 효과음 및 100px+ 대형 당첨 모달 & 폭죽(Canvas Confetti).
  - 외부 음원 파일(mp3) 의존성이 전혀 없어 GitHub Pages 등 정적 웹 환경에서 100% 안정적으로 작동합니다.
- **스마트 모둠 편성기**:
  - **편성 기준 선택**: "모둠당 인원수 기준" 또는 "총 모둠수 기준" 선택 후 균등 분배(결석 번호 자동 제외).
  - **칠판 터치 맞교환 (Click-to-Swap)**: 편성된 카드의 번호를 터치(선택) 후 다른 번호를 터치하면 두 학생의 모둠이 즉시 맞교환됩니다.

### 3. [Tab 2] 실시간 투표 & 익명 건의함 (모바일 연동)
- **학생 스마트폰 즉시 참여 (QR 코드)**:
  - 상단 **[학생 참여 QR]** 버튼을 누르면 칠판에 대형 QR 팝업이 표시됩니다.
  - 학생들은 별도 로그인이나 앱 설치 없이 카메라로 QR을 스캔하여 모바일 전용 간이 화면(`?mode=student`)으로 접속합니다.
- **실시간 찬반/선택 투표**:
  - 교사가 투표 주제 및 2~4개 선택지를 생성하고 시작.
  - 학생 폰에서 투표 즉시 칠판 대시보드에 득표수와 실시간 프로그레스 바 그래프 반영.
- **익명 롤링페이퍼 / 건의함**:
  - 학생들이 100자 이내의 짧은 의견이나 질문을 익명으로 제출.
  - 스마트 칠판에는 알록달록한 포스트잇 스티커 카드로 칠판에 실시간 부착.
  - 부적절한 글이나 확인 완료된 카드는 칠판에서 터치하여 즉시 숨김(보관) 처리 가능.
- **통신 방식**:
  - 같은 기기/교실 내 빠른 시뮬레이션: `BroadcastChannel` 기반 로컬 실시간 동기화.
  - 원격/다중 기기 실시간 중계: 우측 상단 [설정 ⚙️]에서 Google Apps Script(GAS) 또는 Firebase 웹훅 URL 연동 지원.

### 4. 칠판 맞춤형 UX & 편의 기능
- **다크 모드 / 라이트 모드**: 교실 조명 및 채광에 맞춰 원터치 전환.
- **전체화면(F11) 토글**: 브라우저 UI 없이 깔끔한 칠판 모드로 전환.
- **학급 맞춤 설정 ([설정 ⚙️])**:
  - 학급 타이틀 (예: `창원여중 2학년 3반 교실`)
  - 학생 수 설정 (1명 ~ 60명, 기본 25명)
  - 모든 설정과 출결/데이터는 브라우저 `localStorage`에 영구 저장되어 새로고침하거나 전원을 껐다 켜도 유지됩니다.

## 🚀 GitHub Pages 배포 및 접속 방법

1. GitHub 저장소 루트에 `index.html` 파일을 업로드(Push)합니다.
2. 저장소 **Settings** -> **Pages** 메뉴에서 `Branch: main / (root)` 선택 후 **Save**합니다.
3. **교실 스마트 칠판 접속**:
   - `https://[깃허브아이디].github.io/[저장소명]/`
   - 접속 후 우측 상단 [설정 ⚙️]에서 우리 반 이름과 학생 수(예: 25명)를 입력하고 저장합니다.
4. **학생 스마트폰 접속**:
   - 칠판 상단 **[학생 참여 QR]** 버튼을 눌러 나오는 QR 코드를 스캔하거나,
   - 직접 주소 뒤에 `?mode=student`를 붙여 접속합니다:
     `https://[깃허브아이디].github.io/[저장소명]/?mode=student`
