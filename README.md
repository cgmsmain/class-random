# 🏫 스마트 칠판 단일 학급 전용 종합 도구 (Classboard SPA)

스마트 칠판 및 대형 전자칠판 환경에 최적화된 **단일 학급 전용 종합 웹 애플리케이션(SPA)**입니다.  
복잡한 학년/반 선택 단계를 완전히 제거하여 칠판 브라우저를 켜자마자 바로 우리 반 화면으로 로드되며, **출석 번호(1번~N번)** 및 선택적 **이름 명단(CSV 일괄 등록 지원)**을 바탕으로 학급 운영과 수업을 직관적이고 스마트하게 진행할 수 있습니다.

---

## 🌟 주요 핵심 기능

### 1. 대시보드 공통 영역 & 상시 출결 필터 바 (Sticky Header)
- **52px+ 대형 원터치 칩**: 스마트 칠판에서 터치 펜이나 손가락 터치 시 오작동이 없도록 넉넉한 터치 영역 확보.
- **원터치 출석/결석 토글**: 터치 시 출석(초록/파랑) ↔ 결석(회색/취소선) 즉시 전환.
- **실시간 출결 카운터**: `출석 학생수 / 전체 인원 (출석률 %)` 상시 표시 및 전원 출석 리셋 지원.
- **자동 연동 제외 풀**: 결석 처리된 번호는 발표 번호 추첨, 모둠 편성, 자리 배정표 풀에서 즉시 자동 제외됩니다.
- **학생 이름 표기 지원**: 이름이 등록되어 있는 경우 번호 아래에 함께 표시됩니다.

### 2. [탭 1] 🎲 발표 번호 추첨 & 모둠 편성
- **발표 번호 추첨기**:
  - **비복원 추첨(기본)**: 이미 당첨된 번호는 중복 추첨되지 않으며, 당첨 이력 뱃지로 누적 기록.
  - **복원/비복원 토글**: 언제든 중복 허용 방식으로 전환 가능.
  - **시각/청각 연출**: 디지털 롤링 애니메이션, Web Audio API를 활용한 긴장감 넘치는 비프음, 당첨 시 팡파르 효과음 및 100px+ 대형 당첨 모달 & 폭죽(Canvas Confetti).
  - 당첨 팝업 및 누적 목록에 학생 이름이 함께 표시됩니다.
- **스마트 자동 모둠 편성기**:
  - **편성 기준 선택**: "모둠당 인원수 기준" 또는 "총 모둠수 기준" 선택 후 균등 무작위 배분(결석 번호 자동 제외).
  - **칠판 터치 맞교환 (Click-to-Swap)**: 편성된 카드의 번호를 터치(선택) 후 다른 번호를 터치하면 두 학생의 모둠이 즉시 맞교환됩니다.

### 3. [탭 2] 🪑 스마트 자리 배정표 (신규 모듈)
- **그리드 설정 (가로 열 × 세로 행 자유 조절)**:
  - 교실 책상 구조에 맞춰 가로(열: 2~10열)와 세로(행: 2~10행)를 원터치 버튼으로 증감(기본 6열 × 5행).
- **빈자리 / 복도 공간 토글 (`빈자리/복도 지정 모드`)**:
  - 교실의 복도, 기둥, 통로 공간의 책상을 터치하여 '통로(비활성화)' 상태로 지정 가능.
- **시각 기준 (교사 시점 ↔ 학생 시점 원터치 반전)**:
  - **교사 시점(기본)**: 칠판 최하단에 `[ 칠판 / 교탁 ]` 띠가 위치하며, 바로 위가 1행(앞자리), 맨 위가 뒷자리로 정렬되어 교탁에서 학생을 바라보는 시선과 완벽 일치.
  - **학생 시점**: 칠판 최상단에 `[ 칠판 / 교탁 ]` 띠가 위치하며, 학생들이 칠판을 바라보는 기준(상단 앞자리, 하단 뒷자리)으로 원터치 전환 가능.
- **배치 알고리즘 및 편의 기능**:
  - **[🎲 랜덤 자리 배치]**: 현재 출석 상태인 학생들만 활성화된 책상에 무작위 자동 배정.
  - **📌 고정석 지정 (Pin)**: 시력 문제나 특별 지도가 필요한 번호는 좌석 상단 핀을 눌러 고정석으로 지정해 두면, 셔플 시 고정석은 그대로 유지되고 나머지 좌석만 무작위 셔플.
  - **수동 자리 맞교환 (Click-to-Swap)**: 두 책상을 순서대로 터치하면 두 학생의 자리가 즉시 교환.
- **표시 모드 토글**:
  - `[번호만 보기]` / `[번호 + 이름 보기]` 원터치 전환 스위치 지원.

### 4. [탭 3] 🗳️ 실시간 투표 & 익명 건의함 (모바일 연동)
- **학생 스마트폰 즉시 참여 (QR 코드)**:
  - 상단 **[학생 참여 QR]** 버튼을 누르면 칠판에 대형 QR 팝업이 표시됩니다.
  - 학생들은 별도 로그인이나 앱 설치 없이 카메라로 QR을 스캔하여 모바일 전용 간이 화면(`?mode=student`)으로 접속합니다.
- **실시간 찬반/선택 투표**:
  - 교사가 투표 주제 및 2~4개 선택지를 생성하고 시작.
  - 학생 폰에서 투표 즉시 칠판 대시보드에 득표수와 실시간 프로그레스 바 그래프 반영.
- **익명 롤링페이퍼 / 건의함**:
  - 학생이 100자 이내의 짧은 의견이나 질문을 익명으로 제출하면 알록달록한 포스트잇 스티커 카드로 칠판에 실시간 부착.
  - 확인 완료된 카드는 칠판에서 터치하여 즉시 숨김(보관) 처리 가능.
- **통신 방식**:
  - 같은 기기/교실 내 빠른 시뮬레이션: `BroadcastChannel` 기반 로컬 실시간 동기화.
  - 원격/다중 기기 실시간 중계: 우측 상단 [설정 ⚙️]에서 Google Apps Script(GAS) 또는 Firebase 웹훅 URL 연동 지원.

### 5. 환경 설정 & 학생 명단 관리 ([설정 ⚙️])
- **기본 학생 수 설정**: 1명 ~ 60명(기본 25명).
- **학생 명단 관리**:
  - 번호별 학생 이름 입력 및 관리.
  - **엑셀/CSV 일괄 붙여넣기**: 엑셀이나 한글에서 학생 명단을 복사해 붙여넣으면 1번부터 순서대로 자동 매핑.
- **데이터 영구 보존**:
  - 모든 설정, 출결, 학생 명단, 좌석 배치(규격, 빈자리, 고정석, 배정 결과), 추첨 이력 등은 브라우저 `localStorage`에 영구 저장되어 전원을 껐다 켜도 100% 복원됩니다.

## 🚀 GitHub Pages 배포 및 접속 방법

1. GitHub 저장소 루트에 `index.html` 파일을 업로드(Push)합니다.
2. 저장소 **Settings** -> **Pages** 메뉴에서 `Branch: main / (root)` 선택 후 **Save**합니다.
3. **교실 스마트 칠판 접속**:
   - `https://[깃허브아이디].github.io/[저장소명]/`
   - 접속 후 우측 상단 [설정 ⚙️]에서 우리 반 이름과 학생 수, 명단을 입력하고 저장합니다.
4. **학생 스마트폰 접속**:
   - 칠판 상단 **[학생 참여 QR]** 버튼을 눌러 나오는 QR 코드를 스캔하거나,
   - 직접 주소 뒤에 `?mode=student`를 붙여 접속합니다:
     `https://[깃허브아이디].github.io/[저장소명]/?mode=student`
